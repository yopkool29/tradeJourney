En général, dans un footer on trouve :

**Liens essentiels** :
- Mentions légales / Legal
- Politique de confidentialité / Privacy Policy
- Conditions d'utilisation / Terms of Service
- Contact / Support

**Informations** :
- Version de l'application
- Statut du service / Status page
- Documentation / Docs
- Changelog / Release notes

**Réseaux sociaux** :
- Twitter/X, Discord, LinkedIn, etc.

**Autres** :
- Newsletter signup
- Langue / Language selector
- Liens vers blog ou communauté

Pour **TradeJourney** (app locale/self-hosted), je suggérerais :
- **Version** (ex: v1.2.3)
- **Documentation** (si tu en as une)
- **Support/Contact** (email ou Discord)
- Éventuellement **Changelog** ou **Release notes**
